================================================================================
           LANGUAGE LEARNING LMS BACKEND - REST API SPECIFICATION
================================================================================
Base URL: http://localhost:8080
Database: PostgreSQL
Authentication: Bearer JWT Token (RFC 7519)
Paywall Architecture: Freemium model (First 1-2 lessons free, rest locked behind PRO)
================================================================================


TABLE OF CONTENTS
-----------------
1. Authentication & User Management
   - POST   /api/auth/register          [Public]
   - POST   /api/auth/login             [Public]
   - GET    /api/users/me               [Authenticated]

2. Courses & Languages
   - GET    /api/courses                [Public]
   - GET    /api/courses/{id}           [Public]
   - GET    /api/courses/{id}/lessons   [Public / Authenticated]

3. Lessons & Freemium Paywall Gating
   - GET    /api/lessons/{id}           [Authenticated - Freemium Gated]

4. Progress Tracking
   - POST   /api/progress/{id}/complete [Authenticated]
   - GET    /api/progress/courses/{id}  [Authenticated]

5. Payments & Paywall Upgrade
   - POST   /api/payments/checkout      [Authenticated]
   - POST   /api/payments/webhook       [Gateway API Key]
   - GET    /api/payments/history       [Authenticated]

1. AUTHENTICATION & USER MANAGEMENT
------------------------------------

1.1 Register User
-----------------
Method:       POST
Endpoint:     /api/auth/register
Auth:         None (Public)
Description:  Creates a new user account with default subscription_status = 'FREE'.
              Passwords are automatically hashed using BCrypt.

Request Headers:
  Content-Type: application/json

Request Body:
{
  "email": "student@example.com",
  "password": "SecurePassword123!"
}

Success Response (201 Created):
{
  "token": "eyJhbGciOiJIUzI1NiJ9...",
  "tokenType": "Bearer",
  "userId": 1,
  "email": "student@example.com",
  "subscriptionStatus": "FREE"
}

Error Responses:
- 400 Bad Request:
  {
    "timestamp": "2026-09-11T12:00:00",
    "status": 400,
    "error": "Bad Request",
    "message": "Email is already registered: student@example.com",
    "path": "/api/auth/register"
  }

cURL:
curl -X POST http://localhost:8080/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{"email":"student@example.com","password":"SecurePassword123!"}'

--------------
Method:       POST
Endpoint:     /api/auth/login
Auth:         None (Public)
Description:  Validates user credentials and returns a signed JWT token containing
              claims for subject, user ID, and current subscription status.

Request Headers:
  Content-Type: application/json

Request Body:
{
  "email": "student@example.com",
  "password": "SecurePassword123!"
}

Success Response (200 OK):

  "tokenType": "Bearer",
  "userId": 1,
  "email": "student@example.com",
  "subscriptionStatus": "FREE"
}

Error Responses:
- 401 Unauthorized (Invalid credentials):
  {
    "timestamp": "2026-09-11T12:00:00",
    "status": 401,
    "error": "Unauthorized",
    "message": "Invalid email or password",
    "path": "/api/auth/login"
  }

cURL:
curl -X POST http://localhost:8080/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"student@example.com","password":"SecurePassword123!"}'

3. LESSONS & FREEMIUM PAYWALL GATING
------------------------------------

3.1 Fetch Specific Lesson (Paywall-Intercepted Video Delivery)
--------------------------------------------------------------
Method:       GET
Endpoint:     /api/lessons/{id}
Auth:         Yes (Bearer Token)
Description:  Fetches a specific lesson.
              INTERCEPTION LOGIC:
              1. The service layer intercepts the request.
              2. Queries the 'is_free' flag on the lesson.
              3. Checks the user's 'subscription_status' from the security context.
              4. If is_free is false AND subscription_status != 'PRO':
                 Returns HTTP 403 Forbidden with upgrade prompt.
              5. If permitted:
                 Updates or creates user_progress (last_watched_at = now()) and
                 returns the full DTO with the YouTube or Drive video_url.

Request Headers:
  Authorization: Bearer <JWT_TOKEN>

Success Response (200 OK - Free Lesson or PRO User):
{
  "id": 3,
  "courseId": 1,
  "courseTitle": "Japanese N5 Masterclass",
  "title": "Essential Particles: は (wa), を (o), and が (ga)",
  "sequenceNo": 3,
  "free": false,
  "videoUrl": "https://drive.google.com/file/d/1JapaneseGrammarParticlesSample/view",
  "completed": false,
  "lastWatchedAt": "2026-09-11T12:15:30"
}

Paywall Blocked Response (403 Forbidden - FREE User on Paid Lesson):
{
  "timestamp": "2026-09-11T12:15:30",
  "status": 403,
  "error": "Subscription Required",
  "message": "Subscription required to access this lesson. Please upgrade to PRO to unlock full course access.",
  "path": "/api/lessons/3"
}

cURL:
curl -X GET http://localhost:8080/api/lessons/1 \
  -H "Authorization: Bearer <JWT_TOKEN>"

5. PAYMENTS & PRO SUBSCRIPTION UPGRADE
--------------------------------------

5.1 Initiate Paywall Checkout
-----------------------------
Method:       POST
Endpoint:     /api/payments/checkout
Auth:         Yes (Bearer Token)
Description:  Initiates the paywall checkout transaction for the authenticated user.
              Generates a unique transaction_id, inserts a record with status 'PENDING',
              and returns the transaction details.

Request Headers:
  Authorization: Bearer <JWT_TOKEN>
  Content-Type:  application/json

Request Body (Optional / defaults to PRO_MONTHLY $19.99):
{
  "plan": "PRO_MONTHLY",
  "amount": 19.99
}

Success Response (201 Created):
{
  "transactionId": "txn_8803ba97b8304918a5",
  "amount": 19.99,
  "status": "PENDING",
  "message": "Paywall checkout initiated. Complete payment and trigger webhook to unlock PRO features.",
  "webhookSimulatorUrl": "/api/payments/webhook"
}

cURL:
curl -X POST http://localhost:8080/api/payments/checkout \
  -H "Authorization: Bearer <JWT_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{"plan":"PRO_MONTHLY","amount":19.99}'


5.2 Payment Gateway Webhook Listener
------------------------------------
Method:       POST
Endpoint:     /api/payments/webhook
Auth:         Gateway API Key Header: X-Webhook-Secret
Description:  Listens for payment gateway webhook events (e.g. Stripe, Razorpay, LemonSqueezy).
              Validates the X-Webhook-Secret header.
              Upon 'SUCCESS' or 'COMPLETED' event:
              - Updates payment status to 'SUCCESS'.
              - Upgrades the associated user's subscription_status to 'PRO'.
              Immediately unlocks all paid lessons across all language courses for that user.

Request Headers:
  X-Webhook-Secret: sec_test_webhook_key_12345
  Content-Type:     application/json

Request Body:
{
  "transaction_id": "txn_8803ba97b8304918a5",
  "status": "SUCCESS",
  "amount": 19.99
}

Success Response (200 OK):
{
  "id": 1,
  "transactionId": "txn_8803ba97b8304918a5",
  "amount": 19.99,
  "status": "SUCCESS",
  "createdAt": "2026-09-11T12:25:00"
}

Unauthorized Response (401 Unauthorized - Missing or Wrong Secret):
{
  "timestamp": "2026-09-11T12:25:00",
  "status": 401,
  "error": "Unauthorized",
  "message": "Unauthorized: Invalid webhook secret key",
  "path": "/api/payments/webhook"
}

cURL:
curl -X POST http://localhost:8080/api/payments/webhook \
  -H "X-Webhook-Secret: sec_test_webhook_key_12345" \
  -H "Content-Type: application/json" \
  -d '{"transaction_id":"txn_8803ba97b8304918a5","status":"SUCCESS","amount":19.99}'
